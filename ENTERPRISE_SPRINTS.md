## Verification Standards ([`CLIENT_SERVICE_CHARTER.md`](./CLIENT_SERVICE_CHARTER.md))

1. **Deterministic Reproducer (`Exit Code 0`)**: Every bug study starts with an isolated reproduction harness (`verify_fix.py`).
2. **100% Codecov Patch Coverage**: Modified lines, fallback branches, and async paths are verified locally prior to upstream submission.
3. **Maintainer-First Etiquette ([`COMMUNITY_ETIQUETTE.md`](./COMMUNITY_ETIQUETTE.md))**: We inspect assignees, linked PRs, and CI matrices before submitting one focused fix at a time.
