## 🛡️ The 3-Gate Deterministic Selection Rubric (`100.0` Points)

Every Wednesday at **9:23:00 PM EST**, our weekly selection runner scores open submissions labeled `wednesday-923-community-grant`:

1. **Gate 1: Community Safety, Security & Anti-Abuse Gate (`40.0 pts` + Mandatory Pass/Fail Lock)**
   - **Zero Harm Invariant**: Automatically rejects any request involving credential harvesting, exploit payloads, authentication/rate-limit bypasses, scraper automation, DRM circumvention, or proprietary IP.
   - **Anti-Spam Cross-Check**: Verifies submitter authenticity so automated spam accounts cannot game the queue.
   - **Permissive Open-Source Attestation**: Requires explicit `MIT` / `Apache-2.0` / `BSD` compatibility.
2. **Gate 2: Global Developer & Public Benefit Score (`35.0 pts`)**
   - Prioritizes high-leverage public good across 7 categories: AI Agent/MCP/Streaming Hardening, Zero-Dependency CLI Diagnostics, Upstream Bug Fixes, Accessibility (`a11y`), Low-Resource Language/Speech, Open Science, and Browser Verification Labs.
3. **Gate 3: Community Demand & Reproducibility (`25.0 pts`)**
   - Scores clear deterministic verification criteria (`Exit Code 0`) and GitHub community reactions (`👍`, `❤️`, `🚀`).
